# P1-3 方案：给 HTML 站点加列表页翻页，提升中标（award）数据

## 背景
- 驾驶舱所在 `tender_monitor/scrapers.py` 的 HTML 站点（世纪新城/盐东方/经开城发/大数据/都市/悦达/三峡/农华/瑞康/国投）**只抓列表页第 1 页**，不翻页。
- 中标公告（award）多在列表页后面的页面。实测世纪新城第 2 页有 10 条中标公告，第 1 页只 6 条。
- 目标：通过翻页抓到更多 award，提升招标→中标闭环价值。

## 各站分页 URL 模式（已实测确认）
| 站点 | Scraper | 第1页 URL | 第N页 URL 模式 |
|---|---|---|---|
| 世纪新城 | CommonListScraper | `.../tender/` | `.../tender/index_N.html` |
| 盐东方 | CommonListScraper | `.../zbzl/qzzgs/` | `.../zbzl/qzzgs/index_N.html` |
| 经开城发 | CommonListScraper | `.../zbcg/zbxx/` | `.../zbcg/zbxx/index_N.html` |
| 大数据 | YcDataGroupScraper | `.../news/19.html` | `.../news/19-N.html` |
| 都市 | YcDsjtScraper | `.../?zhaobiao/` | `.../?zhaobiao_N/` |
| 悦达 | YdSunshineScraper | `.../zbgg/index.jhtml` | `.../zbgg/index_N.jhtml` |
| 三峡 | CtgScraper | `.../1ywgg1/index.htm` | 分页链接为 `javascript:;`，需 JS 或改用其它 | 
| 农华 | JsNonghuaScraper | `.../type_id/8.html` | `...?type_id=8&page=N` |
| 瑞康 | RkyyScraper | `.../node/118` | `.../node/118_N` |
| 国投 | SdiccScraper | `.../cgxx/ggList` | 无可见分页链接 |

## 实现要点
1. **在 BaseScraper 增加翻页能力**，提供 `extra_pages`（默认 2，即抓第1页+第2页，共 2 页），或 `max_pages`。
2. **每站给出 `get_page_url(base_url, page)` 方法** 生成第 N 页 URL（按上表模式）。
3. **翻页去重**：跨页用 `seen` set 去重（每站的 parse_list 已有 seen，需保证跨页共享或用全局 URL set）。
4. **翻页数量控制**：默认抓 2 页（第 1 页 + 第 2 页），避免过度抓取和反爬。可配置。
5. **三峡/国投**：分页不可靠（三峡 `javascript:;`，国投无链接），这两站保持只抓第 1 页，不强行翻页。
6. **抓取顺序**：先抓第 1 页，再抓第 2 页，合并 items，再统一抓详情页。注意详情页抓取仍按现有 `scrape()` 流程。
7. **异常隔离**：某页失败不中断整站，跳过该页继续。

## 改动的文件
- `tender_monitor/scrapers.py`：BaseScraper 翻页基类 + 各站 get_page_url + CommonListScraper 等翻页支持
- `tender_monitor/config.py`：可选加 `MAX_LIST_PAGES` 配置（默认 2）

## 验证
- 改完跑 `python3 run.py`（或先单站测试某站），确认：
  - 世纪新城 items 数从 80 → 约 160（2 页）
  - award 数量明显增加
  - 无重复标题
- 跑 `python3 rebuild_ict.py` 重新生成 tender.json（若只改抓取需重跑 run.py）
- 部署 `docker cp site/. cockpit:/usr/share/nginx/html/`

## 风险与注意
- 翻页会**增加抓取耗时**（每页 + 详情页）。当前江苏政府采购网已占 6 分钟，全部站点翻页可能增加 3-5 分钟，需确认老板可接受。
- 反爬风险：翻页更频繁，部分站点可能触发限流。建议翻页间隔用现有 `REQUEST_DELAY`。
- 只抓 2 页是保守策略，能覆盖大部分近期中标公告，又不至于太重。
- 都市集团日期只有"日"数字跨月会出错（既有问题，翻页不改）。

## 执行方式
本方案由子会话用 minimax-m3 模型执行。执行完成后：
1. 单站验证（世纪新城翻页）
2. 跑完整 run.py（后台）
3. rebuild_ict.py 生成 tender.json
4. 部署到 cockpit
5. 汇报结果
