# cockpit-tender

盐城市招投标信息采集与驾驶舱展示系统（纯代码备份）

## 简介
抓取政府采购/招投标公开公告（中国政府采购网、江苏政府采购、苏服采等），
清洗富化后入库，前端驾驶舱展示，支持区县归属人工修订。

## 目录结构
- `collector/` — 采集、清洗、富化、质量门禁、部署调度
- `frontend/` — 驾驶舱前端（tender.js / tender.css）
- `api.py` + `api_service.sh` — 区县修订 API
- `collector/README.md` — 详细维护手册

## 说明
- 本仓库为代码备份，**不含业务数据**（数据库、采集 JSON、日志均不入库）
- 涉及内部运维信息的文档已脱敏（服务器地址以 `<SERVER_IP>` 占位）
- 维护：内部项目，代码供学习与归档参考
